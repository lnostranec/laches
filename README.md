# «Название» — сайт мастера по наращиванию волос

Одностраничный сайт: HTML + CSS + JS, отправка заявок в Telegram через `send.php`.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Главная страница (все секции) |
| `styles.css` | Стили, адаптив |
| `script.js` | Меню, анимации, маска телефона, отправка формы |
| `send.php` | Принимает заявку и шлёт её в Telegram-бота |
| `config.example.php` | Шаблон настроек → скопировать в `config.php` |
| `privacy.html` | Политика конфиденциальности (шаблон, заполнить `[...]`) |
| `404.html`, `.htaccess` | Страница ошибки, защита конфига, кеш |

## Запуск на хостинге (Beget / Timeweb / любой с PHP)

1. Залить все файлы в корень сайта (`public_html`).
2. Скопировать `config.example.php` → `config.php`, вписать:
   - `bot_token` — токен от @BotFather;
   - `chat_ids` — chat_id Яны (ей нужно написать боту `/start`, затем открыть
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `message.chat.id`).
3. Отправить тестовую заявку с сайта.
   Если сообщение не пришло — смотреть лог ошибок PHP в панели хостинга.
   Если хостинг не достучался до `api.telegram.org`, указать `proxy` в `config.php`.

## Локальный запуск

```bash
php -S localhost:8090
```

## Что заменить перед запуском

- «Название» — в `index.html`, `privacy.html`, `404.html`
- Цены и тексты услуг, цифры в hero (5+ лет, 1000+ клиенток)
- Город/район, телефон, ссылки на Telegram/VK (`https://t.me/` → `https://t.me/username`)
- Фото: сейчас стоят **временные** фото с Unsplash (ссылки `images.unsplash.com`).
  Положить свои в `assets/` и заменить `src` у `<img>` (первый экран, «Обо мне», 6 фото в галерее).
- Данные оператора в `privacy.html`
